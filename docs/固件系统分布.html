工厂区(SN/MAC)：设备身份存于 Flash 保留区（工厂区解码见 身份与工厂区_SN_MAC.md）。 本固件 system.sn 取自此，用于激活密码 P_act=UPPER(first16(MD5(NVR_sn+dev_sn))) 与录像 AES 密钥派生。

2. Linux 文件系统挂载布局

只读根 可写配置 overlay/tmpfs 录像盘(SATA)

├── /flash             ubi (mtd8, 可写)  rc.conf / hostname / resolv.conf / ini
├── /dvr               主程序目录        ← 本固件二进制 + 配置(见 §3)
│   └── tutk_cloud_agent  tmpfs  TUTK 云代理
├── /mnt
│   ├── /mnt/custom    tmpfs/overlay  ⭐ LVGL 界面配置(GUI_CONFIG.json / gui_cfg.ini / 字体)
│   ├── /mnt/sda1..4   ext4 录像盘  4×~116GB(见 §4)
│   ├── /mnt/usb       U 盘(vfat)  导出/OTA .rom 暂存
│   └── /mnt/disk /mnt/nfs …  预留挂载点
├── /config            设置库/元数据    ← nvr_settings.db · meta.db (SQLite)
├── /webroot           overlay  Web 回放 (var/www/img01..04 → /mnt/sdaN)
├── /etc/init.d/S99nvr 开机自启 → 看护脚本
└── /tmp  /var/run     tmpfs           ← update.rom 下载暂存等
根为 squashfs 只读 + A/B 双 rootfs：固件升级写另一个 rootfs 分区再切换（OTA upgradeFirmware 下载 .rom → 更新器烧写 → 重启切分区）。可写状态只在 /flash、/config、/mnt/*。

交互：界面 ↔ NVR 经 http://127.0.0.1:8089/APPJsonCmd(NOP JSON)。NVR 命令路由：本地命令存/查 SQLite；面向通道命令按 channel→真实设备IP，NightOwl(NOP/nopOnvif) HTTP 透传、通用 ONVIF 走映射翻译成 SOAP。
