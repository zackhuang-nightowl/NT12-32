## 2026-08-06 · 只保留 8089 监听,移除其他所有监听服务

**目的**:NVR 只保留 8089(`nop_http_server`,GUI 入口)一个网络监听;移除所有其他监听 server。

**背景核实**:live 路径只启动 `nop_http_server_start(8089)`([nvr_app.c:441](../app/src/nvr_app.c#L441))。以下监听 server 在真实路径**从不启动**(仅 test/example 引用),属死码:
- app 路由自建 HTTP 服务(`listen_fd=-1` 永不监听)
- `nop_rtsp_server`(RTSP 端口)
- `nop_event8012_server`(8012 端口)
- `nop_unix_server`(Unix 域套接字)

**保留**:8089 `http_server`;netlink 热插拔(`storage_hotplug.c`,非网络端口监听);event8012 **client**(出站连相机,非监听);unix **client 连接器**(`nop_channel_unix_connect`,非监听)。

**基线**:改动前 `cmake --build build` = ✅ 通过。

### 改动明细

| # | 文件 | 改动 | 状态 |
|---|---|---|---|
| 1 | app/router/nvr_cmd_router.c / .h | 移除死码独立 HTTP 服务(`read_line`/`handle_conn`/`server_main`/`nvr_cmd_router__unused`/`nvr_cmd_router_port`)+ struct 字段(listen_fd/port/running/thr)+ 无用头(pthread/socket 等) | ✅ 完成 |
| 2 | components/nop/src/media/rtsp_server.c(+头 nop_rtsp_server.h) | 删整文件(RTSP 监听,零 live 引用) | ✅ 完成 |
| 3 | components/nop/src/services/camera/svc_event8012.c(+头 nop_event8012.h) | 删整文件(8012 server 监听,零 live 引用;client 保留) | ✅ 完成 |
| 4 | components/nop/CMakeLists.txt | 移除 rtsp_server.c / svc_event8012.c 源条目 | ✅ 完成 |

> 注:transport_unix(Unix 域套接字)是**本地 UI 进程 IPC**,非网络端口监听,且混客户端连接器 + 被 example 依赖 → 归为架构决策,本轮**未动**,待单独确认。
