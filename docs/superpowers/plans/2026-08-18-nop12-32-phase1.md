### Task 5: build.sh（一键出 NOP12_32_<VERSION>.bin）

**Files:**
- Create: `nop12-32/build.sh`（可执行）

**Interfaces:**
- Consumes: `VERSION`、`rootfs/`、`bootchain/`、`partitions/`、`sdk/nvtpack/nvtpack`、nvr_firmware 交叉构建。
- Produces: `nop12-32/out/NOP12_32_<VERSION>.bin`（全量）+ `NOP12_32_<VERSION>_ota.bin`（可选 OTA）。

- [ ] **Step 1: 写 build.sh**

```bash
cat > nop12-32/build.sh <<'EOF'
#!/bin/bash
set -e
HERE="$(cd "$(dirname "$0")" && pwd)"
VERSION="$(tr -d ' \r\n\t' < "$HERE/VERSION")"
NVR_SRC="/home/zack/NT12-32/nvr_firmware"
NVTPACK="$HERE/sdk/nvtpack/nvtpack"
OUT="$HERE/out"; mkdir -p "$OUT"

echo "== [1/5] 交叉构建 nvr_app =="
cmake --build "$NVR_SRC/build_arm" --target nvr_app -j"$(nproc)"
cp -f "$NVR_SRC/build_arm/app/nvr_app" "$HERE/rootfs/dvr/bin/nvr_app"
chmod 755 "$HERE/rootfs/dvr/bin/nvr_app"
echo "   nvr_app md5=$(md5sum "$HERE/rootfs/dvr/bin/nvr_app" | cut -d' ' -f1)"

echo "== [2/5] mksquashfs rootfs =="
RAW="$HERE/partitions/rootfs.squash.bin.raw"
mksquashfs "$HERE/rootfs" "$RAW" -comp xz -b 131072 -noappend -all-root >/dev/null
cp -f "$RAW" "$HERE/partitions/rootfs1.bin"     # 槽 B = 同镜像
echo "   rootfs $(du -h "$RAW" | cut -f1)"

echo "== [3/5] 汇集分区到 partitions/(nvtpack 工作目录) =="
for f in loader fdt fdtr atf uboot kernel; do cp -f "$HERE/bootchain/$f.bin" "$HERE/partitions/"; done

echo "== [4/5] nvtpack 全量 =="
( cd "$HERE/partitions" && "$NVTPACK" -fw FW98633A.ini )
mv -f "$HERE/partitions/packed/FW98633A.bin" "$OUT/NOP12_32_${VERSION}.bin"

echo "== [5/5] nvtpack OTA(引导链+rootfs,不动数据分区) =="
( cd "$HERE/partitions" && "$NVTPACK" -fw FW98633A_ota.ini ) && \
  mv -f "$HERE/partitions/packed_ota/FW98633A.bin" "$OUT/NOP12_32_${VERSION}_ota.bin" || echo "   (OTA 可选,跳过)"

echo "完成: $OUT/NOP12_32_${VERSION}.bin ($(du -h "$OUT/NOP12_32_${VERSION}.bin" | cut -f1))"
EOF
chmod +x nop12-32/build.sh
```
