## 五、相对原设计的已知偏差（RSDK v2 · 文档 §13 已说明）

> RSDK v2 P0–P3 已落地；下列为相对 [rsdk-v2 spec §3/§13](superpowers/specs/2026-08-20-rsdk-v2-reliable-recording-design.md) 的**有意或未改项**，汇总便于 8-22 验收对照。细表见 [CODE_GAP_AUDIT §4.6 / §6](CODE_GAP_AUDIT.md)。

| # | 项 | 现状 | 代码 / 说明 |
|---|-----|------|-------------|
| 1 | **线程模型** | 未拆 per-disk worker | 仍为**单 record worker** + 盘组**共享递归锁**（元数据串行、数据区 `pread`/`pwrite` 无锁）。正确性已保证；多机械盘并行写吞吐优化留后续。`stream_record_worker.c` · `rsdk_balance.c` |
| 2 | **writer 生命周期** | open/close 仍在 puller | `stream_router.c` 仍由 puller 调 `rsdk_rec_open`/`close`，未完全交给 worker；元数据有锁保护。worker 注释仍提示需 **writer 归属重构** 以彻底消除 UAF 风险。 |
| 3 | **wall_time** | 入队时刻非 RTP 映射 | puller `on_video` 仍用 **`time(NULL)`** 打采集时刻，**RTP delta Time Mapper 未实现**。对写盘延迟够用；跨相机时钟漂移见 streaming README TODO。`stream_router.c` |
| 4 | **Rel4 pread 短读** | 越界补 0 当成功 | `rsdk_rawdev.c:48` 仍对越界读**补零返回成功**，未按原设计 Rel4 **显式报错**；v2 帧载荷 CRC 可在回放侧检坏帧。 |
| 5 | **SEG_CLOSE 标记** | 数据区未写 | 关段以索引槽 **VALID + fsync** 为权威（含 `end_time`/`frame_count`/`total_bytes`），**未额外写数据区 SEG_CLOSE**；扫描重建靠帧头自描述。spec §13 偏差 2。 |
| 6 | **§10 集成测试** | 无自动化 | TSan 并发压测、**32 路 soak**、**拔盘** stress 等在设计 §10 列出，**代码库尚无自动化**；需真机验收。见 [CODE_GAP_AUDIT §6](CODE_GAP_AUDIT.md)。 |

**正式写入 spec §13 的「有意偏差」**：上表 **#1（线程模型）**、**#5（SEG_CLOSE）** 两条；其余 **#2–#4、#6** 在 [CODE_GAP_AUDIT](CODE_GAP_AUDIT.md) / [ARCHITECTURE](ARCHITECTURE.md) 可靠性遗留中跟踪。
