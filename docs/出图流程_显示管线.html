buffer（拉流侧）：无独立帧队列，回调内同步处理；仅参数集缓存 par[512] + 动态关键帧缓存 kf。

2NAL 处理与帧路由

nal_classify 扫 Annex-B 起始码，识别 SPS/PPS/VPS 与 IDR，输出 is_key/is_param/frame_type。stream_route_video 两条扇出：

扇出行为
解码 / 出图仅 decode_stream 那一路喂解码器（单通道一个硬解器）；从 IDR 起播（live_synced 前丢 P 帧）→ mhal_vdec_send
录像主+子都写，各自 keyframe 门控；写原始帧（非拼接版）

主/子选择（核心下采样决策）：默认 decode_stream = SUB（多宫格 720p）；单画面切主码流（8K/1080p）。两路常拉，切换即时无重连。

4硬解配置（mhal_vdec → hd_videodec）

// 路径建立（dev 0, id=chn）
hd_videodec_open(IN(0,chn), OUT(0,chn))   → dec_path
hd_videoproc_open(IN(chn,0), OUT(chn,0))  → proc_path (VPE)
hd_videoout_open(IN(0,chn), OUT(0,0))     → vout_path
hd_videodec_bind(dec→proc)  hd_videoproc_bind(proc→vout)
  • 对齐：解码维度 64×64 对齐（CTU 要求，否则解不出帧）；上限 8192²，默认 1920×1088。
  • 解码池 data_pool[0] 全分辨率、环深 3；bs_counts=8，max_bitrate=8Mbps，像素 NV12。
  • DDR 分池：比特流→DDR0、全分辨率→DDR1、sub-yuv→DDR1（放错就无图）。

送帧 hd_videodec_send_list（Annex-B，fourcc VSTM）；抓拍 hd_videodec_pull_out_buf。

5缩放 / 下采样（两级）

5.1 解码器级 sub-yuv 下采样（仅 8K，宽 > 4096）

8K 主码流超 VPE 输入上限（~4K）→ 命解码器直吐 1/2 小图：SUB_YUV_RATIO = 2x，7680×2176 → 3840×1088。下采样输出走 data_pool[1] RATIO 池（DDR1）；8K 比特流 max_bs_size=2MB × bs_counts=4 = 8MB（装下 IDR 又不撑爆 20.3MB DIN 池）。

5.2 VPE 级 source→cell 缩放（每帧上屏）

apply_window：hd_videoproc_set(OUT, rect=格子) 把解码源 d->w×d->h 缩到目标格（如 1080p 源 → 16 宫格 480×270）。

6数字变焦裁剪（ZoomPan）已实现

接口 X_NightOwl_set/getChannelZoomPan。机制：在 VPE 输入端设裁剪 ROI（HD_VIDEOPROC_PARAM_IN_CROP），VPE 只取 ROI 再放大填满窗口 = 数字变焦。相当于在 §5.2 的 source→cell 缩放之前，先把"源"从整帧收窄成一块 ROI。

接口约定（坐标千分比 0..1000，ratio 100=1.00x，MAX 500=5.0x）
字段含义
CenterPointX/YROI 中心（原画千分比）
ZoomRatio倍率，100=原画；≥500 → 夹到 500 且 result=Exceeds zoom capabilities
enable=false复位全画面（500,500,100）
返回 resultOK / Exceeds the zoom range(平移越界被夹) / Exceeds zoom capabilities(超倍率)

三层实现

层文件职责
handlernvr_cmd_display.ccmd_..._setChannelZoomPan 解析入参 → 调 preview → 回填实际生效值
previewnvr_preview.cnvr_preview_set_zoom：算 ROI（等比、夹边界）、存每通道状态
mhalmhal_vout.cmhal_vout_set_crop → hd_videoproc_set(IN_CROP) 真驱动 VPE

ROI 数学（preview 层）

// ratio: 100=1x … 500=5x ; 坐标千分比
if (ratio >= 500) { ratio = 500; result = "Exceeds zoom capabilities"; }
cw = 1000 * 100 / ratio;          // ROI 宽(千分):ratio 200 → 500(半宽)；ch=cw 保持宽高比
x  = clamp(cx - cw/2, 0, 1000-cw);// 中心夹取,越界→ result="Exceeds the zoom range"
y  = clamp(cy - ch/2, 0, 1000-ch);
cx = x + cw/2;  cy = y + ch/2;    // 回填实际生效中心
mhal_vout_set_crop(chn, x, y, cw, ch);   // 千分比 ROI

驱动（mhal 层）

// 千分比 → 源像素(d->w/h 已 64 对齐),4 对齐并夹在帧内
HD_VIDEOPROC_CROP crop = {0};
crop.mode      = HD_CROP_ON;          // 恒 ON;取消变焦=全帧 rect,不切模式
crop.win.coord = {0,0};              // {0,0}=像素坐标
crop.win.rect  = { cx, cy, cw, ch }; // 源 ROI
hd_videoproc_set(proc_path, HD_VIDEOPROC_PARAM_IN_CROP, &crop);
if (!crop_on) { hd_videoproc_start(proc_path); crop_on = 1; } // OFF→ON 只 start 一次
要点：裁剪窗恒用 HD_CROP_ON，"取消变焦"= 设全帧 rect（不切模式，免重启）；模式仅首次 OFF→ON 切一次并 start。ROI 按源画面 4 对齐并夹在帧内，保持原画宽高比。掉电/重启回默认 500,500,100（每通道状态存 preview，不落 DB）。
注：数字变焦作用于单画面（该通道解码器上屏那一路）。FocusPointXY v1 未单独锚定（GUI 已据焦点算好 Center 下发）。切主/子码流会重开解码器 → 变焦复位，需 GUI 重下发。

7出图 / 分屏（mhal_vout → hd_videoout）

HDMI 模式：3840×2160P30 / 1920×1080P60 / 1280×720P60（input_dim 必须显式，AUTO 会退到 720×576 越界）。

分屏 rect：方阵 1/4/9/16/25/36 → n=1..6 均分；8 宫格 = 1 大(3×3)+7 小。越界窗口隐藏（visible=0）而非下发屏外矩形。

成图 mhal_vout_commit：先 stop_list 旧集合 → 再 start_list 新集合（dec→proc→vout 顺序），任一时刻只需 1 块 large graph（根治 "Can't extend"）。defer 批量：切宫格 begin/end 包住所有 open/close，一次成图。清黑：CLEAR_WIN 填 UYVY 中性黑 0x00800080。

桩 OSD mhal_vout_osd 目前是 TODO（暂不做，后补）。

8硬解预算门控（mhal_budget）

总量 746.496 Mpix/s（=1920×1080×360，数据手册硬解上限）；开销 cost=w×h×fps；try_reserve 超预算 → 拒绝该路预览（录像不受影响），返回 MHAL_VDEC_EBUDGET → UI "仅录像不预览"。

9预览编排（app/preview/nvr_preview.c）

唯一调用 mhal_vout_* 的模块。set_mode(mode,page)：mode=0 退出 LiveView（停解码保留拉流/录像）；否则先关不可见页省预算 → 按 mode 选主/子码流 → set_display 开解码 → commit。切页/切宫格无重连。wait_ready 轮询 display_ready（20ms/次，超时 2000ms），供 "等图出了再回复"。

11编译门控 / real vs stub
