# 实现：Playback 协议对齐（事件检索 / Control / Audio / USB Backup）

> 日期: 2026-08-12  
> 依据: `nop_api_doc/GUI_Ext/Playback/*` + `NOP_APP/X_NightOwl_queryEvent*`  
> 产品裁决: PlaybackMsgNotify 按文档样例 + 设备实态; `setPlaybackAudio` 按接口多路开启即开启。

---

## 已实现

| 接口 | 要点 |
|------|------|
| `X_NightOwl_queryEventList` | meta `DOC_CLOUD` 优先 + 连续轨 `RSDK_RK_EVENT` 兜底; `latest` 倒序; `eventTypes`/`channels`/`queryID`/`listNumber`; 返回 `list[]` 字段对齐文档 |
| `X_NightOwl_queryEventCalendar` | 同上数据源按本地日历聚月/日(不再依赖 `RSDK_SLOT_EVENT`) |
| `GUI_playbackControl` | 倍速 frame/0.125…8X; >4X I-only; backward=I 倒放(预扫 ≤1h); 日界停; 同 startTime 改速不重开; `PlaybackMsgNotify` 按实态 |
| `GUI_get/setPlaybackAudio` | `enable[]` 按格; 缩布局丢尾; 多格同时为 1 全部接受 |
| `GUI_ChannelBackupFiles` / `Get…Status` / `StopChannelBackup` | 单任务线程 + `rsdk_backup_export` → `/mnt/usb[2]`; Abort By User |
| `getPlaybackCapabilities` | 如实报 streamType + 全容量 channels; protocol 空(远程隧道未通) |

## 能力 / Notify 文案

- 超 `nvr_gui_config_max_playback_channels()` → `Cannot support simultaneous playback more than N channels.` + `status=notSupport`
- mode0 多通道(多路主流) → main-stream 文案 + notSupport
- 倍速 >8X → clamp 8X + fast-forward 文案
- 4K 预算不足 → `Cannot support 4K decoding for ChannelX.`(其它路可继续)

配置读取:`GUI_CONFIG.json` 的 `allPlaybackDisplayModes` / `channels`。
