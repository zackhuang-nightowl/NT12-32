03

裸盘 RSDK 分区布局

每块 /dev/sdX 格式化后 magic RSDK01。视频帧在 DataRegion；IndexRegion 在 RSV 内；MetaRegion 占 chunk 池尾部（抓拍 JPEG + 大 JSON）。

/* 512B 扇区 · 自 sector 0 起 */ Sector 0 Protective MBR + 0x55AA Sector 1–2 SuperBlock (main + backup) magic "RSDK01\0\0" Sector 3–18 SysTab (main + backup) magic 'STAB' AllocBitmap (main + backup) 2 bits/chunk IndexRegion 64B × (chunk_count × slots_per_chunk) ── RSV 结束 ── data_start_sec DataRegion chunk[0 .. N-1] 8/16/32 MiB/chunk · 环形覆盖 └─ 尾部 meta_chunk_count 个 chunk = MetaRegion (默认 0.5%)

▸容量示例（chunk=8MiB, slots=4, meta=0.5%）

磁盘chunk_countRSV+索引MetaRegion视频数据
500 GB59,600~32 MiB~2.3 GiB~463 GiB
2 TB238,403~120 MiB~9.3 GiB~1.8 TiB
18 TB2,145,635~1.0 GiB~84 GiB~16.3 TiB

▸DataRegion 帧记录

rsdk_frame_hdr_t 64B magic "rsdkfrm\0" + 通道/时间/PTS/codec … payload H.264/H.265/AAC 裸流 对齐 128B (RSDK_FRAME_ALIGN)

0x10frame_countu32
0x14total_bytesu64

05

MetaRegion — 元数据区 & 图片区

MetaRegion 在裸盘 chunk 池尾部，由 SysTab 环形分配。小文档 (≤4KB) 可 inline 进 meta.db；大 JSON / JPEG 存盘上并写指针。

图片区 · rsdk_pic_hdr_t
magic "PIC0" · 40B + JPEG

type: 0=target 1=main 2=scene 3=cover
enc: 0=plain 1=AES-256-CTR
绑定 event_id + ts + chn

元数据 blob · rsdk_mdoc_hdr_t
magic "MDOC" · 32B + JSON

doc_type 与 meta_doc 一致
enc bit0=AES bit1=gzip

▸模拟 · 事件抓拍 PIC0（storage=1）

/* 盘上 MetaRegion */ PIC0 chn=13 event_id=10769 ts=1784486092 type=1 (main) enc=0 w=320 h=240 jpeg_len=18432 /* 后跟 JPEG 字节 … */ /* meta.db 索引行指向 */ meta_disk=0 meta_off=0x2A1F800 meta_len=18472 doc_type=5 (RSDK_DOC_SNAP) json='{"pic":1,"w":320,"h":240}'

▸模拟 · AI 事件 MDOC（大 JSON → MetaRegion）

MDOC event_id=10769 ts=1784486092 doc_type=1 (AI_EVENT) json_len=8192 enc=1 (AES) /* 盘上 JSON 原文（节选） */ { "ts": 1784486092, "chn": 13, "event": "human", "objects": [{ "id": 7, "cls": "person", "conf": 0.92, "bbox": [0.12,0.08,0.26,0.64], "color": "red" }], "seg": { "chunk": 12040, "off": 384, "pts": 90000 } }
混合策略（rsdk_features.conf）：JSON ≤ 4KB → meta.db inline（storage=0）；更大 → MetaRegion（storage=1）。
06

meta.db — 元数据索引库

路径：/flash/nvrcfg/meta.db。出厂无行；事件/录像/AI/抓拍运行时写入。仅 1 张业务表 meta_doc。

列类型用途
idINTEGER PK自增
ts, ts_msINTEGER主检索键（epoch）
chnINTEGER通道
event_idINTEGER与录像/抓拍同一事件
doc_typeINTEGER1=AI_EVENT 2=AI_FRAME 3=LPR 4=FACE 5=SNAP 6=ALARM …
seg_disk/chunk/off/ptsINTEGER视频 seek 绑定
storageINTEGER0=inline json · 1=MetaRegion 指针
encINTEGER0=明文 · bit0 AES · bit1 gzip
json_len, jsonINT,TEXTstorage=0 时完整 JSON
meta_disk/off/lenINTEGERstorage=1 时盘上 MDOC/PIC0
