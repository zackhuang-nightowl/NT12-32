## 链路 1 · 命令入口与路由

**拓扑**:三个外部入口最终都进 `nvr_cmd_dispatch`
```
GUI  ──8089 nop_http_server──┐
APP  ──TUTK agent (P2P)──────┼──► nvr_cmd_dispatch ──► ①本地表 / ②NOP透传(只改channel) / ③ONVIF映射
配网 ──BLE ble_dispatch_bridge┘
```
**现状**:三入口 + 三级分流全部活跃(`nvr_cmd_router_start` 在 nvr_app.c:432 装配,处理器 `nvr_cmd_dispatch` 被 8089/BLE/... 调用)。

**死块 —— 路由内的「独立 HTTP 服务」**:`nvr_cmd_router_start` 里 `listen_fd=-1; running=0`,**永不监听、永不起线程**,路由只当请求处理器用。
