## ⑥ 录像写库 / 落盘（录像路径，与显示并行）

分层：**puller 线程**(每路码流一个，只入队) → **RecordQueue**(每路一个环形队列) → **单一 Record Worker 线程**(串行写盘)。前缀 `rsdk_` = 录像 SDK(`components/recorder`)。

### 6.1 喂帧路径（入队 → 出队写盘）

| 环节 | 定位 | 说明 |
|---|---|---|
| 入队(puller) | `stream_router.c:253-282 stream_record_enqueue()` | 视频入队 `p->rec_q`；队满→"丢到下个 IDR + 打 gap"(`:266-273`)，盘追上后从 IDR 无缝续录；`stream_record_enqueue_audio() :284-295` 音频挂主流 |
| 唤醒 | `stream_record_worker_poke()` | 入队后唤醒 worker |
| Worker 主循环 | `stream_record_worker.c:270 record_worker_thread()` | `worker_round() :242` 公平轮询 `NVR_MAX_CH*2`(主/子)路 |
| 出队 | `worker_drain_pull() :161` | 每路每轮最多 512KB(`REC_WORKER_BYTE_BUDGET`)；拷贝后解锁再写盘(`:197-209` 缩短持锁) |
| 组帧写盘 | `worker_write_slot() :102-158` | 组 `rsdk_frame_t` → `rsdk_rec_write_frame`(视频 `:157`/音频 `:128`)；`f.stream` 主=0/子=1/音频=2 |
| 周期 sync | `worker_periodic_sync() :216` | 每 1s `rsdk_rec_datasync`，压低掉电丢失窗口 |

| writer 打开点 | `stream_router.c:537 stream_open_writer()`(连续) / `:211 stream_event_writers_open()`(事件) | |

### 6.2 分段(chunk) + 关键帧表 + 时间轴索引

- **分段模型**：一个 RecSegment 落在单个 chunk 内(`rsdk_rec.c:1-3`)；chunk 大小 = `SuperBlock.chunk_sectors*512`，格式化按容量 auto(256M 为典型值)。
- **切段触发**：容量满自动切(`rsdk_rec_write_frame :190-193`)；主动 IDR 对齐切(worker 关键帧且近满 `stream_record_worker.c:143-147 rsdk_rec_rotate()`，判据 `rsdk_rec_chunk_near_full() rsdk_rec.c:177-181` 剩<10%)；兜底 `REC_SEG_MAX_SECONDS=3600`。`rsdk_rec_rotate() :332-337` 闭段+开新段，下一帧保证 IDR → 段界无缝。
- **关键帧表(段内 seek)**：`kf_record() :33-44` 每 IDR 记 `(wall_time, chunk_off)`(上限 4096)；段闭合 `flush_keyframes() :48-66` 整表作为 `RSDK_RK_KEYIDX` 记录写进本 chunk(`finalize_seg :129`)；条目 `rsdk_kf_entry_t rsdk_types.h:175-178`。
- **段索引(时间轴)** `rsdk_index.c`：环形 64B `rsdk_index_slot_t`(`rsdk_types.h:183-201`，含 start/end_time、start/end_chunk、frame_count、stream)；段首写 OPEN 槽(`rsdk_rec.c:199-201`)，闭合写 VALID(`:132-133`)；`rsdk_index_write() :45` 环形写+chunk→slot 加速表 O(1) upsert；`rsdk_index_load_map() :20-43` 开盘扫索引区建加速表(`rsdk_storgedev.c:337` 调)；检索 `rsdk_index_query_stream`/`_foreach_stream`(后者无 cap 截断，供日历/进度条)。

### 6.3 元数据落库 —— meta.db + 盘上权威区

**架构要点**：段索引、事件、抓拍、云存态 **不进 meta.db，走盘上权威区**（可扫盘重建）；meta.db 只装可丢的富 AI 元数据边车。

| 存什么 | 在哪 | 定位 |
|---|---|---|
| 段索引(时间轴) | 盘上段索引区 | `rsdk_index.c`(见 6.2) |
| 事件/抓拍/云存态 | 盘上 128B **事件索引区** `rsdk_evt_slot_t` | `rsdk_types.h:207-229`(event_id/rectype/state 云存态/av_disk/av_chunk/av_off/snap_off/snap_len/attempts/last_err)；API `rsdk_evtidx.c`(`_write :52`/`_get :77`/`_query :85`/`_patch_snap :110`/`_patch_state :126` 云存态/`_invalidate_chunk :142`)；写入点 `rsdk_rec.c:298 mark_event`/`:308 end_event`/`:318 mark_cloud`(内部 `evt_slot_upsert :278` 同时写槽+数据区自描述标记)；上层触发 `stream_record_worker.c:46-79 worker_apply_event_tags` |
| 富 AI 元数据 | **meta.db**(SQLite,WAL) 单表 `meta_doc` | `rsdk_meta.c:10-23 SCHEMA`(id/ts/chn/event_id/doc_type/seg_*/json 等，6 索引含车牌 `ix_meta_plate`/类别 `ix_meta_cls`)；类型 `rsdk_doc_type rsdk_meta.h:19-27`(AI_EVENT/AI_FRAME/LPR/FACE/ALARM/POS)；API `_open :25`/`_put :36`(原样存 JSON)/`_query :57`(json_extract 深查)/`_purge :127`；写入点 `app/src/nvr_app.c:295`，打开 `:1029` |

### 6.4 录像调度（何时录 / 录哪路 / 事件触发）

配置表 schema（`components/config/src/nvr_settings.c`）：
- `record_config`(`:92-95`)：`chn, record_on, triggers(如 'human,face,vehicle'), stream_type(默认 'both')`
- `record_schedule`(`:97-99`)：`chn, sched_on, rules(JSON 周排程秒级区间)` 持续录像排程
- `schedule`(`:114-117`)：`chn, domain, sensor, rule_id, weekdays, start_hms, end_hms` 事件录像/云存时段
- 迁移：老 `stream_type='main'` → `'both'`(`:429`)

stream_type → 主/子掩码（`components/config/src/nvr_record_policy.c:9-27 nvr_record_stream_mask()`）：`both`→主子都开，`main`→仅主，`sub`→仅子，`disable`→都关。

调度评估（`app/src/nvr_app.c:1316-1354 rec_schedule_apply()`，每 5s 或配置变更）：
- 读 `record_config`+`record_schedule`+`schedule` 规则计数
- `continuous = record_on && sched_on && rules_match_now(...)`(`:1329`)
- `event_arm = record_on && evt_saved && !continuous`(`:1330`)
- RTC 未就绪挂起(`:1332`)，绝不产生 1970 时间轴
- 应用：`nvr_stream_set_record_mask`(主/子)/`nvr_stream_set_record`(连续)/`nvr_stream_set_event_arm`(事件+预录)
- 掩码落通道 `stream_mgr.cpp:235-238`(设 `rec_main_on/rec_sub_on`)

事件触发协调（`app/record_sched/nvr_record_sched.c`，只做事件/云存登记+满盘策略）：`nvr_rec_trigger_event() :81-139`(铸 event_id、同类型 10min 内续录延长、云存门控、post-record)；`nvr_rec_tick() :150-169`(后录到期/达 10min → 闭事件 → `rsdk_rec_end_event`)。

### 6.6 双轨录像（主+子，stream_type=both）

每通道两个独立 writer `c->writer_main`/`c->writer_sub`，各自独立段索引：
- 开两路：连续 `stream_router.c:537-556`(rec_main_on 开主/rec_sub_on 开子)；事件 `:211-232`
- 各有独立 puller + RecordQueue：worker `pull_of :39`/`writer_of :34` 按 stream 选主/子，`worker_round` 遍历 `NVR_MAX_CH*2`(`idx%2` 区分)
- 写盘打标 `f.stream` 主=0/子=1/音频=2，写入 `slot.stream`(`rsdk_rec.c fill_slot :124`)，供按码流检索
- 音频只挂主流 writer(`stream_record_worker.c:116-128`)；事件标签双路都打(`rsdk_rec_set_event` 主 `:55`+子 `:67`)，`mark_event`/`mark_cloud` 只在主流(事件槽以主流定位为权威)
