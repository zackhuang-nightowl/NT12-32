| 我拟的字段 | 含义 | 你定的值 |

## §3. 回放布局/倍速/音频细节(P3/P4)

### 3.1 宫格布局 displayMode

doc:`0`=特制全屏、`1`=1宫格、`4`/`8`=对应宫格数,"清单由需求配置文件确定"。
- NT12-32 回放支持哪些 layout? (如 `0,1,4,8,9,16`?)
  **【答:和liveView一样读取配置文件】**
- 与直播宫格清单一致吗? **【答:和直播宫格一致】**

### 3.2 倍速档位

doc 全集:`frame` / `0.125X` / `0.25X` / `0.5X` / `1X` / `2X` / `4X` / `8X`。
- 全部支持,还是子集? **【答:全部支持】**

### 3.3 音频出声细节

- **同时几路出声**:硬件音频输出通常**单路**。若 `setPlaybackAudio` 多个宫格 enable=1,取**第几个**?(建议:只放最后一个置1的宫格,其余忽略)
  **【答:按接口控制，只有一个channel音频能开启】**
- **音频编码**:录像主路存 AAC。回放解码 AAC→PCM→hd_audioout 即可,确认无 G711 等其它需处理? **【答:NVR上使用G711U,AAC是为了给APP使用的。】**
- **默认**:进回放默认全静音(enable 全 0),由用户点开? **【答:默认都静音，只能有一个打开】**

### 3.4 单画面导出按钮(GUI 文档提到 single view 里 "Export current event")

- 这个"导出当前事件"属于 **P5 导出**。**本轮(P3/P4)是否包含 P5?** 还是 P3/P4 先出,P5 单独一轮?
  **【答:先完成p3和p4】**

## §4. 其它可能影响 P3/P4 的点

- **回放期录像是否继续**:进回放时录像引擎不停(继续写盘),只是预览解码让位给回放解码,确认? **【答:继续写盘  录像只受DB的配置控制，只要开着就需要一直录制】**
- **多路回放选道与时间轴联动**:GUI 勾选通道→`setPlaybackMode` 带 channels[];引擎按此开对应路。跨通道**共用同一 startTime/speed/direction**(统一时间轴)对吧? **【答:是的，共用的】**
- **跨段间隙(gap)**:`rsdk_group_play_next2` 能报录制间隙>2s。遇间隙**画面冻结等到下一段** 还是 **直接跳到下一段**? **【答:按时间来播放  遇到该时间所有channel都空才会跳，只要时间点有录像就需要播  没有的channel就冻结等到有再继续播】**
