## 二、关键根因与修复(排查记录)

- **ONVIF 能力空**:相机 media2 profile 精简无音频/分析 → **media1 兜底合并**;媒体服务需鉴权(HTTP 401/WS `NotAuthorized`),空密码不带 token → 改**按 DB 账密带 token**;后又回滚为**匿名优先/仅 DB 有密码才试密码**(PoE 匿名回归)。
- **PoE 掉线不恢复**:原写死 `.1`+ARP 门控;相机在 `198.18.<seg>.1`(seg 含 VLAN2001=NVR 偏移)→ 改 **ONVIF 发现 + 真实 IP 直连重连**。
- **回放后全黑**:`pb_stop` 只清黑不归还 live → 加**恢复 live 布局**。
- **回放喂空 footage 花屏/DE 刷屏**:回放请求无录像的时间/通道 → 解码器 `scan first header error` 刷屏并可 wedge(待加**无 footage 保护**)。
- **queryRecordingInterval 看似空**:实为**未传 year/month/day**(需传);录像其实在写(`/proc/diskstats` sda ~5.7MB/s),时窗按本地日界(`local_ymd_epoch`)与 UTC 录像时间戳一致。

## 五、关键技术点(避坑)

- **PoE 通道↔VLAN↔网段**:VLAN 2001=NVR 保留;PoE 口 P → VLAN 200(P+1) → 网段 `198.18.(P+1).x`;相机常在 `.1`,NVR 在 `.100`。发现源 IP 必须是 NVR 在该 VLAN 的 `.100`(绑定网卡多播)。段号从通道 `onvif_ip` 第 3 段取,自动对上偏移。
- **8089 命令服务串行**:单 `serve_loop` 线程、handler 内联、一次一请求;handler 必须非阻塞(回放/事件 handler 只置状态,重活交后台线程)。
- **writer 线程归属**:录像 writer 由 puller 线程独占写;命令/事件线程改写(录像开关/事件标记)只置标志,由 puller 应用,禁止跨线程直接写/关 writer(UAF)。
- **持久化分区**:`/tmp/nvrcfg` 是 RAM rootfs(重启丢);持久数据(两 .db + channels.json)落 `/flash/nvrcfg`(ubifs);OTA .ini 跳过数据分区。
- **回放视频区**:mode0 全屏,否则 0.8×0.8@(0,0);GUI 时间轴/控件占右/下。
- **刷机**:`pack_ota.sh` 打 squashfs.raw → NFS → 设备 `flash_erase /dev/mtd6|7` + `nandwrite -p` 刷非活动槽 → `echo 0|1 > /User/ROOTFS_MTD` 切槽 → reboot。
