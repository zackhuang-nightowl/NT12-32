# NT12-32 NVR 固件 — 分区 / Linux 系统分布 / 使用的库

> SoC：Novatek NT98633 / NA51090（4×Cortex-A53，aarch64，Linux 4.19，Buildroot）。
> 板载 SPI-NAND 128 MB + SATA HDD。固件 `nvr_app`（12.8 MB，ELF aarch64）。
> 可视化版：[固件系统分布.html](固件系统分布.html)（本地打开）。

## 1. 板载 Flash 分区（SPI-NAND 128 MB，12 个 MTD，erase 128 KB）
| MTD | 大小 | 内容 | 说明 |
|---|---|---|---|
| mtd0 loader | 256 KB | Bootloader | 一级引导 |
| mtd1 fdt / mtd2 fdt.restore | 256 KB ×2 | 设备树 + 备份 | DTB |
| mtd3 atf | 256 KB | ARM Trusted Firmware | 安全引导 |
| mtd4 uboot | 3.5 MB | U-Boot | 二级引导 |
| mtd5 kernel | 5.5 MB | Linux 4.19 内核 | |
| **mtd6 rootfs / mtd7 rootfs1** | 40 MB ×2 | **根文件系统 A/B 双备份** | squashfs 只读，升级切换 |
| mtd8 flash | 14 MB | 可写配置区(ubi) | 挂 `/flash`；rc.conf/hostname/resolv.conf 软链到此 |
| mtd9 SYS | 12 MB | 系统数据 | |
| mtd10 User | 12 MB | 用户数据 | |
| mtd11 all | 128 MB | 整片映射 | 整盘操作用 |

> 工厂区(SN/MAC)存于 `/User`（ubifs，OTA 不覆盖）；固件经 `nvr_identity` 读取，不走 settings 库。

## 2. Linux 文件系统挂载布局
```
/                      squashfs 只读 (/dev/romblock7 → /ROOTFS，assert=read-only)
├── /flash             ubi (mtd8, 可写)  rc.conf / hostname / resolv.conf / ini
├── /dvr               主程序目录        ← 本固件二进制 + 配置(见 §3)
│   └── tutk_cloud_agent  tmpfs  TUTK 云代理
├── /mnt
│   ├── /mnt/custom    tmpfs/overlay  ⭐ LVGL 界面配置(GUI_CONFIG.json/gui_cfg.ini/字体)
│   ├── /mnt/sda1..4   ext4 录像盘  4×~116GB(见 §4)
│   ├── /mnt/usb       U 盘(vfat)  导出/OTA .rom 暂存
│   └── /mnt/disk /mnt/nfs …  预留挂载点
├── /flash/nvrcfg      设置库/元数据  ← nvr_settings.db · meta.db · channels.json
├── /User              ubi (mtd10)  身份权威源：OWLSerialNumber / mac_addr_v2 / tutk_agent_udid / OWLModel / OWL/tutkdata.json
├── /SYS               ubi (mtd9)   系统数据
├── /config            历史路径（部分部署文档仍写此处；实码优先 /flash/nvrcfg）
├── /webroot           overlay  Web 回放 (var/www/img01..04 → /mnt/sdaN)
├── /etc/init.d/S99nvr 开机自启 → 看护脚本
└── /tmp /var/run      tmpfs  ← update.rom 下载暂存等
```
> 根为 **squashfs 只读 + A/B 双 rootfs**：升级写另一个 rootfs 再切换（OTA .rom → 更新器烧写 → 重启切分区）。可写在 `/flash`、`/User`、`/SYS`、`/mnt/*`。

## 3. 本固件部署位置（`deploy/rootfs/` → 合并进设备根）
| 设备路径 | 内容 |
|---|---|
| `/dvr/bin/nvr_app` | 本固件(aarch64, 12.8M) |
| `/dvr/bin/NO_xVR_GUI_...argb1555` | LVGL 界面(独立进程) |
| `/dvr/bin/nvr_supervisor.sh` | 看护脚本(起 NVR→等8089→起界面→崩溃重启) |
| `/dvr/bin/nvr_do_update.sh` | OTA A/B：刷非活动 rootfs + 切 `/User/ROOTFS_MTD` + reboot |
| `/dvr/config/*.json` | NVR 配置(首启种子 → nvr_settings.db) |
| `/flash/nvrcfg/nvr_settings.db` · `meta.db` · `channels.json` | SQLite 运行期库 + 通道持久化（OTA 跳过） |
| `/User/OWLSerialNumber` · `mac_addr_v2` · `tutk_agent_udid` · `OWLModel` · `OWL/tutkdata.json` | 身份权威源（`nvr_identity`；OTA 不覆盖） |
| `/mnt/custom/*` | 界面配置(字体/GUI_CONFIG/http_debug) |
| `/etc/init.d/S99nvr` | 开机自启 |

## 4. SATA HDD 录像分区（NVR 格式化 → 4×ext4）
| 分区 | 大小 | FS | 挂载(录像) | Web 回放 |
|---|---|---|---|---|
| sda1 | ~115.8 GB | ext4 | /mnt/sda1 | /webroot/var/www/img01 |
| sda2 | ~115.8 GB | ext4 | /mnt/sda2 | /webroot/var/www/img02 |
| sda3 | ~115.8 GB | ext4 | /mnt/sda3 | /webroot/var/www/img03 |
| sda4 | ~115.8 GB | ext4 | /mnt/sda4 | /webroot/var/www/img04 |

挂载参数 `rw,noatime,nodiratime,commit=15,data=ordered`。原厂 ext4 明文；本固件 `recorder` 另提供**裸盘直写**(AES-256-CTR + 10MB 环形块 + 索引)，上真机二选一。

## 5. 使用的库

### 5.1 自研静态库
`nvr_app_core`(整机集成) · `nopcore`(NOP 核 + ONVIF 映射) · `rsdk`(录像引擎) · `nvr_streaming`(主+子常拉) · `nvr_onvif`/`nvr_dev_classify`(取流/三分类) · `nvr_storage`(盘管理) · `nvr_settings`(SQLite + `nvr_identity`) · `nvr_crypto`(MD5/SHA/AES256) · `nvr_cloud_uploader`(云存上传) · `nvr_cloud_tutk`(live RTSP :8554) · `mhal`(vdec/vout/aout)

### 5.2 第三方（vendored / 预编译）
| 库 | 版本 | 形态 | 用途 |
|---|---|---|---|
| cJSON | — | 源码(唯一副本) | JSON |
| SQLite | 3.45.3 | 合并源 | 设置库/元数据(自包含) |
| Happytimesoft ONVIF/RTSP | — | 源码交叉编 | RTSP 拉流 + ONVIF 客户端 |
| OpenSSL(头) | 1.1.1g | 头 + 链 .so.3 | TLS/摘要 |
| libcurl(头) | 8.5.0 | 头 + 链 .so.4 | 云存/OTA/转发 HTTP |
| TUTK SDK | ArmCortexA53_NT98633_8.4.0 | 预编译 .so | P2P(IOTC + P2PTunnel) |
| libsrt/libsrtp | arm64-v8a | 预编译 .a | happytime 依赖 |
| ffmpeg | arm64-v8a | 预编译(备用) | 软解兜底 |
| na51090 BSP(hdal) | — | 预编译 libhdal.so | 硬解/上屏 |

### 5.3 运行期动态依赖（设备 rootfs 需具备，原厂固件均带）
`libssl.so.3` · `libcrypto.so.3` · `libcurl.so.4` · `libIOTCAPIs.so` · `libAVAPIs.so` · `libhdal.so` · `libstdc++/libgcc_s/libpthread/libdl/libm/libc`
> OpenSSL 头 1.1.1 vs 设备库 3.x：EVP 用法两版兼容；真机报符号则换 openssl-3 头重编。
